# 出图(独立流程)

判断类(母版选择、版式、卡片分层与摆位由执行者定,按 `sum-svg-diagram` skill 六步作业流程),不占初始化/更新流程编号,随时可独立触发。总则见 [`README.md`](./README.md)(入口分诊)。

覆盖全部四类图(链路局部图 3.1 / 全局业务图 3.2 / 业务全貌图 3.3 / 全局架构图 3.4),不区分业务页/概览页。本流程内**不做任何"要不要画"的判断**——四类图槽位在组装步骤(`GOVERNANCE_FLOW_INIT` 的 `step6-assemble.md`、`GOVERNANCE_FLOW` 的 `overview-init.md` 步 2)一律已机械插入标准真链接,链接指向的文件要么是占位图、要么是真图,不存在"没有图"这个状态。本流程唯一的职责,是把占位图换成真图(或直接生成一张此前从未占位过的真图),不产出任何"不需要图""判'不画'"一类的结论或标注。

## 触发时机

- 建页/概览组装完成后,原本插入的是占位图,需要补真图。
- 已有真图对应的业务内容发生变化,需要重画(内容是否已过期是触发者当场判断的事,本流程本身不做"要不要重画"的判断,只负责重画这个动作)。
- 想给某张已有图升级画法或修正误画时。

## 范围

- (可选辅助)定位当前项目里还挂着占位图的槽位:对 `DATA_IMAGES` 下全部 `.svg` 文件执行 `grep -rl "sum-svg-diagram · 占位待画资产"`(命中的文件即判"应画但未画",内容非最终;`DATA_IMAGES` 的实际相对路径查 `ENTRY_PATHS`(路径表自身)。也可以不经此步骤、直接指定要画哪一张图。
- 对目标图,原样执行 `sum-svg-diagram` skill 六步作业流程(复制骨架 → 画前内容清单 → 只换内容 → 数量伸缩 → 渲染自查+画后内容核对 → 交付);skill 正文不在本文件复述,执行者直接读该 skill。事实源与落位命名按 `GOVERNANCE_RULES` 的 `diagram-rules.md` 对应节(3.1/3.2/3.3/3.4)指向。

## 产出

画完的 SVG 以约定文件名(命名规则见 `GOVERNANCE_RULES` 的 `diagram-rules.md` 五"落盘与引用")直接覆盖同名占位文件(首次出图则新落盘该文件名)。md 正文对应位置的链接行本就是标准真链接格式(见 `ENTRY_AGENTS` 一行链接写法),画完不需要改写链接行文字——占位阶段与画完阶段用的是同一行链接,只有链接目标指向的文件内容变了。

## 注意

- 本流程不判断"要不要画""值不值得画";四类图槽位在组装步已必须有真链接,本流程唯一的工作是让链接指向的文件从占位内容变成真内容。
- 可一次只处理一张图,也可一次处理多张图,互不依赖,可任意顺序执行。
- 不改 `DATA_BUSINESS` 下业务页与 `ENTRY_OVERVIEW` 的正文链接行文字本身(除非文件名/图名本身变化,那属于另一种改动,不在本流程范围内)。
- 本流程随时可重跑,不要求跟随任何其它流程的批次节奏。

## 通过判据

按 `GOVERNANCE_RULES` 的 `diagram-rules.md` 六(通过判据)核对:结构比对 `sum-svg-diagram` skill 对应母版一致;内容取材于该图对应节(二节)指向的事实源,经 skill 六步作业流程"画前内容清单/画后内容核对"两道关卡确认无遗漏、无编造;SVG XML 安全(`&`/`<`/`>` 转义、注释无三连短横或箭头符号);文件已存入约定路径,md 正文对应位置存在且仅存在一行指向该文件的链接,链接路径实际可解析到该文件。

- 硬规则 7(图槽位必占位,判断不入建页流程)(`GOVERNANCE_RULES` 的 `assembly-rules.md` 二.7)
